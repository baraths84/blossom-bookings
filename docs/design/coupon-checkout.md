# Coupon checkout design

Preserve the shared Bookings blue light/dark theme in `src/styles.css`, type, logo, cards and spacing. Use its semantic color tokens so both themes stay consistent. Add a labeled coupon input above the price summary, Apply and Remove buttons, accessible error text and an applied state. Show nightly subtotal, coupon savings and final total in USD, keeping cents when needed. There are no taxes or fees in this demo. Confirmation shows the code and saved amount. Coupon management uses labeled fields and explicit active/inactive actions, available through the footer at /coupons.
