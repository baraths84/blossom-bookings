# Blossom Bookings

Add this clone to Codex as the **Blossom Bookings** project. In a **Local** chat on main, select the checked-in environment, follow the setup command for your operating system in START-HERE.md if needed, and choose **Preview app**. Open the URL it prints to browse stays and make a demo reservation.

For local **Worktree** chats, use [the exercise map](docs/exercise-starters.md) to prepare the starter names. Select the environment when you create the worktree so setup runs in that checkout. For 301 on an assigned seat, follow the guide to add the prepared Ubuntu folder as a remote project. Open a chat in that project and leave **Work in** set to **Remote**. Return to the same chat to resume your edits. The ZIP's START-HERE.md covers setup, verifying starting commits, and the optional draft PR in your own private repository.
