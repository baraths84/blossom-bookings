---
name: definition-of-done
description: Verify a Blossom Bookings change before handoff.
---

Read the ticket acceptance criteria. Add regression tests for changed behavior. Run `npm test`, `npm run lint`, and `npm run build`. Exercise the affected route in the browser, including a success path and error state; check keyboard access and mobile layout. Report exact commands, results, remaining intentional checkpoint failures and unverified behavior. Do not mark a failing requirement complete or weaken a test.
